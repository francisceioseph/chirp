Psito Chirp

Talk straight to each other.

A private messenger with no servers in the middle: conversations go from one device to the other, over the local network or the internet, encrypted end to end. No accounts, no phone numbers, no logs and no telemetry.

Install Source code

What it does

  • One-to-one conversations, encrypted with the Signal protocol, with post-quantum key agreement
  • Works on the local network with no internet at all, and over the internet when you turn it on
  • Add a contact by QR code or with an invite link that works once
  • Delivery and read receipts, typing, replies, edits, reactions, nudges and search
  • Photos (without location data), files and voice notes, sent in encrypted pieces
  • Messages wait and go out on their own when the contact shows up
  • Notifications that can hide the name and the text, and the tray icon on the desktop

What it protects, and what it doesn't

The content of your messages and files, from anyone on the network, from your internet provider and from a relay; the database on your device, encrypted with a key kept in the system keychain; and there is nothing of yours on a server of ours, because there isn't one.

It doesn't protect a device with malware, doesn't hide that you use Chirp from someone watching the local network, and, with the internet on, your contacts see your IP address. A contact can always keep or share what you send them.

Install

Windows

On Windows 10 or 11, on x64. Installing for everyone asks for administrator rights and lets contacts on the local network reach you; installing just for you doesn't, and Windows asks about the network the first time.

Download the installer

SmartScreen may warn about an unknown publisher, because the installer isn't signed with a paid certificate. Choose More info, then Run anyway.

Android

On Android 8 or newer. No Google services needed.

Download the APK

Your phone asks to allow installing from the browser. Updates come the same way, from this page.

Debian, Ubuntu, Mint

On Debian 13, Ubuntu 24.04, Mint 22 or newer, on amd64. It updates along with the system.

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://francisceioseph.github.io/chirp/psito-chirp.asc | sudo tee /etc/apt/keyrings/psito-chirp.asc >/dev/null
printf 'Types: deb\nURIs: https://francisceioseph.github.io/chirp\nSuites: stable\nComponents: main\nArchitectures: amd64\nSigned-By: /etc/apt/keyrings/psito-chirp.asc\n' | sudo tee /etc/apt/sources.list.d/psito-chirp.sources >/dev/null
sudo apt update
sudo apt install psito-chirp
To remove it, and the repository 
sudo apt remove psito-chirp
sudo rm /etc/apt/sources.list.d/psito-chirp.sources /etc/apt/keyrings/psito-chirp.asc

Fedora

On x86_64. It updates along with the system. The first install asks you to accept the signing key.

sudo curl -fsSL -o /etc/yum.repos.d/psito-chirp.repo https://francisceioseph.github.io/chirp/psito-chirp.repo
sudo dnf install psito-chirp
To remove it, and the repository 
sudo dnf remove psito-chirp
sudo rm /etc/yum.repos.d/psito-chirp.repo

macOS

A test build, not signed by Apple. After dragging it to Applications, open it with a right click and Open, and confirm.

Download the disk image

On iPhone and iPad, for now, only building from source with Xcode. Every download has its SHA-256 in SHA256SUMS, on the releases page.
